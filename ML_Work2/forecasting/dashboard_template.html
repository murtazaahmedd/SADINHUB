    Unusual consumption alerts

    Every day, each meter's actual consumption is compared with what the forecast expected that morning. Meters that behave unusually are listed here so someone can check them. An alert means "unusual – worth a look", not a proven fault.

    How to read the alerts

    What the colours mean

    Red ▲ used more than expected.

    Amber ▼ used less than expected.

    Grey ● meter data problem: readings missing or broken, so that day is not judged at all.

    How a day becomes an alert

      Which method found it

      Both methods the simple rule and the ML model agree.

      Simple rule only the gap from the forecast is at least 3 times this meter's typical forecast error.

      ML model only the ML model (Isolation Forest) rated the day unusual when it looked at several signals together, even though the gap was under 3 times the typical error. The model does not give its reasons; the note shown with each ML-only alert is the largest of the simple comparisons, for reference, not the model's own reason.

      What an alert is not

      • Not proof of a fault – someone checks the cause.
      • Not money saved – savings only count after action is taken.
      • A permanent change (for example a new tenant) shows for the first days, then the forecast learns it and it becomes the new normal.
      • Missing readings are never counted as 0 kWh; they appear as data problems.
